# ReNotes

Aplicación móvil desarrollada en Flutter para la asignatura Programación para Dispositivos Móviles.

Por Alejandro Jesús Del Llano Hernández

## Descripción

ReNotes permite organizar proyectos de investigación, crear y editar notas, clasificarlas mediante etiquetas y realizar búsquedas.

## Instalación y ejecución

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar los siguientes comandos en la terminal:

```bash
flutter pub get
flutter run
```
